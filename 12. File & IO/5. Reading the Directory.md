#### Reading the Directory
- Often when working with files it is necessary to read the directory listing. C# provides the Directory class and GetFiles method for this purpose. The method definition is as follows:


#### `Directory.GetFiles()` – Quick Reference Table

| Overload | Parameters | Description | Example |
| :--- | :--- | :--- | :--- |
| **1** | `string path` | Returns **all files** in the specified directory. | `Directory.GetFiles(@"C:\Temp")` |
| **2** | `string path, string searchPattern` | Returns files matching a **search pattern** (supports `*` and `?` wildcards). | `Directory.GetFiles(@"C:\Temp", "*.txt")` |
| **3** | `string path, string searchPattern, SearchOption searchOption` | Returns files matching a pattern, with option to search **subdirectories**. | `Directory.GetFiles(@"C:\Temp", "*.txt", SearchOption.AllDirectories)` |

#### Example Code (Based on Your Image)

Here's a complete example that demonstrates all three overloads:

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string directoryPath = @"C:\Temp";

        // Check if the directory exists
        if (!Directory.Exists(directoryPath))
        {
            Console.WriteLine($"Directory '{directoryPath}' does not exist.");
            return;
        }

        Console.WriteLine("=== Method 1: GetFiles(path) ===");
        string[] allFiles = Directory.GetFiles(directoryPath);
        Console.WriteLine($"Total files: {allFiles.Length}");
        foreach (string file in allFiles)
        {
            Console.WriteLine($"  {Path.GetFileName(file)}");
        }

        Console.WriteLine("\n=== Method 2: GetFiles(path, searchPattern) ===");
        string[] txtFiles = Directory.GetFiles(directoryPath, "*.txt");
        Console.WriteLine($"Total .txt files: {txtFiles.Length}");
        foreach (string file in txtFiles)
        {
            Console.WriteLine($"  {Path.GetFileName(file)}");
        }

        Console.WriteLine("\n=== Method 3: GetFiles(path, searchPattern, SearchOption.AllDirectories) ===");
        string[] allTxtFiles = Directory.GetFiles(directoryPath, "*.txt", SearchOption.AllDirectories);
        Console.WriteLine($"Total .txt files (including subdirectories): {allTxtFiles.Length}");
        foreach (string file in allTxtFiles)
        {
            Console.WriteLine($"  {file}"); // Shows full path for clarity
        }
    }
}
```

#### Summary: When to Use Each Overload

| Scenario | Recommended Overload |
| :--- | :--- |
| You need **all files** in a single folder. | `GetFiles(path)` |
| You need **files of a specific type** in a single folder. | `GetFiles(path, "*.txt")` |
| You need **files of a specific type** in a folder **and all subfolders**. | `GetFiles(path, "*.txt", SearchOption.AllDirectories)` |
