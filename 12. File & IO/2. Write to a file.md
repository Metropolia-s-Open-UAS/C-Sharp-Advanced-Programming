#### `StreamWriter` – Overview

| Aspect | Details |
| :--- | :--- |
| **Namespace** | `System.IO` |
| **Purpose** | Writes characters to a file in a specific encoding |
| **Default Behavior** | Creates a new file or **overwrites** (truncates) an existing file |
| **Key Methods** | `Write()`, `WriteLine()`, `WriteAsync()`, `Dispose()` |
| **Best Practice** | Always use `using` statement to ensure proper disposal |

#### Basic `StreamWriter` Example (Based on Your Description)

Here's the complete code from your image:

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string fileName = "output.txt";
        string content = "Hello, World!\nThis is a test file.";

        // Using statement ensures the file is closed and resources are released
        using (StreamWriter writer = new StreamWriter(fileName))
        {
            writer.Write(content);
        }

        Console.WriteLine($"Content written to {fileName}");

        // Verify by reading and displaying
        string readContent = File.ReadAllText(fileName);
        Console.WriteLine("\nFile contents:");
        Console.WriteLine(readContent);
    }
}
```

**Behavior:**
- If `output.txt` doesn't exist → Creates it
- If `output.txt` exists → **Overwrites** (truncates) it

#### Table 1: Ways to Write to a File

| Method | Description | Example |
| :--- | :--- | :--- |
| **`StreamWriter.Write()`** | Writes a string without a newline. | `writer.Write("Hello");` |
| **`StreamWriter.WriteLine()`** | Writes a string with a newline. | `writer.WriteLine("Hello");` |
| **`File.WriteAllText()`** | Simplest method - writes a string to a file (overwrites). | `File.WriteAllText("file.txt", "Hello");` |
| **`File.WriteAllLines()`** | Writes a string array to a file (overwrites). | `File.WriteAllLines("file.txt", lines);` |
| **`File.AppendAllText()`** | Appends text to the end of a file. | `File.AppendAllText("file.txt", "More");` |
| **`File.AppendAllLines()`** | Appends an array of strings to a file. | `File.AppendAllLines("file.txt", moreLines);` |

#### Using `StreamWriter` with `using`

The `using` statement ensures that:
1. The file is properly closed
2. The stream is disposed
3. Resources are released immediately

```csharp
// Correct way (with using)
using (StreamWriter writer = new StreamWriter("data.txt"))
{
    writer.WriteLine("Line 1");
    writer.WriteLine("Line 2");
} // Automatically calls Dispose() and closes the file

// Equivalent without using (manual disposal)
StreamWriter writer = null;
try
{
    writer = new StreamWriter("data.txt");
    writer.WriteLine("Line 1");
    writer.WriteLine("Line 2");
}
finally
{
    if (writer != null)
        writer.Dispose(); // Manually close and dispose
}
```

#### Overwriting vs Appending

| Scenario | Code | Behavior |
| :--- | :--- | :--- |
| **Overwrite (truncate)** | `new StreamWriter("file.txt")` | Replaces all existing content |
| **Append** | `new StreamWriter("file.txt", true)` | Adds to the end of the file |
| **Append (simpler)** | `File.AppendAllText("file.txt", "text")` | Adds to the end of the file |

**Example:**

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string filePath = "log.txt";

        // Overwrite (default)
        using (StreamWriter writer = new StreamWriter(filePath))
        {
            writer.WriteLine("This will overwrite everything!");
        }

        // Append (second parameter 'true' means append)
        using (StreamWriter writer = new StreamWriter(filePath, true))
        {
            writer.WriteLine("This will be added to the end.");
        }

        // Even simpler append
        File.AppendAllText(filePath, "This is also appended." + Environment.NewLine);

        Console.WriteLine(File.ReadAllText(filePath));
    }
}
```

**Output:**
```
This will overwrite everything!
This will be added to the end.
This is also appended.
```

#### Comprehensive Error Handling

Writing to files can fail for many reasons. Here's robust error handling:

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string fileName = "output.txt";
        string content = "Important data to save.";

        try
        {
            using (StreamWriter writer = new StreamWriter(fileName))
            {
                writer.Write(content);
            }
            Console.WriteLine($"Successfully wrote to {fileName}");
        }
        catch (DirectoryNotFoundException ex)
        {
            Console.WriteLine($"Directory not found: {ex.Message}");
        }
        catch (PathTooLongException ex)
        {
            Console.WriteLine($"Path is too long: {ex.Message}");
        }
        catch (UnauthorizedAccessException ex)
        {
            Console.WriteLine($"Access denied: {ex.Message}");
        }
        catch (IOException ex)
        {
            // This covers: disk full, file locked, network error, etc.
            Console.WriteLine($"I/O error: {ex.Message}");
        }
        catch (Exception ex)
        {
            Console.WriteLine($"Unexpected error: {ex.Message}");
        }
    }
}
```

#### Table 2: Common File Write Errors and Solutions

| Error | Cause | Solution |
| :--- | :--- | :--- |
| **`DirectoryNotFoundException`** | The directory in the path doesn't exist. | Create the directory first: `Directory.CreateDirectory(path)` |
| **`PathTooLongException`** | Path exceeds system limit (usually 260 chars). | Use shorter path or `\\?\` long path syntax. |
| **`UnauthorizedAccessException`** | Insufficient permissions, or file is read-only. | Run with appropriate permissions, or remove read-only attribute. |
| **`IOException`** | Disk is full, file is locked, network error, etc. | Free disk space, close other programs, check network. |
| **`ArgumentException`** | Invalid characters in path. | Use `Path.GetInvalidPathChars()` to validate. |

#### Creating Directories Before Writing

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string filePath = @"C:\MyApp\Data\output.txt";
        string directory = Path.GetDirectoryName(filePath);

        // Ensure the directory exists
        if (!Directory.Exists(directory))
        {
            Directory.CreateDirectory(directory);
            Console.WriteLine($"Created directory: {directory}");
        }

        // Now write the file
        File.WriteAllText(filePath, "Hello, World!");
        Console.WriteLine($"File written to: {filePath}");
    }
}
```

#### Using Different Encodings

By default, `StreamWriter` uses UTF-8 encoding. You can specify other encodings:

```csharp
using System.IO;
using System.Text;

// UTF-8 (default)
using (StreamWriter writer = new StreamWriter("file.txt"))
{
    writer.Write("Hello");
}

// UTF-16 (Unicode)
using (StreamWriter writer = new StreamWriter("file.txt", false, Encoding.Unicode))
{
    writer.Write("Hello");
}

// ASCII
using (StreamWriter writer = new StreamWriter("file.txt", false, Encoding.ASCII))
{
    writer.Write("Hello");
}
```

#### Writing Large Files Efficiently

For large files, `StreamWriter` with `WriteLine` is efficient because it writes in a buffered manner:

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string filePath = "largefile.txt";
        int totalLines = 1_000_000;

        using (StreamWriter writer = new StreamWriter(filePath))
        {
            for (int i = 1; i <= totalLines; i++)
            {
                writer.WriteLine($"Line {i}: This is line number {i}");
                
                // Show progress every 100,000 lines
                if (i % 100000 == 0)
                {
                    Console.WriteLine($"Written {i} lines...");
                }
            }
        }

        Console.WriteLine($"File with {totalLines} lines created.");
        Console.WriteLine($"File size: {new FileInfo(filePath).Length / 1024 / 1024} MB");
    }
}
```

| **Choose overwrite vs append** | Default is overwrite; use `true` parameter for append. |
