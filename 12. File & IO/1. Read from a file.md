#### 1. Read from a file
- [ ] In this chapter we learn how to read and write to an external file.
- [ ] We also learn how to to delete a resultant file.
- [ ] As it is often the case in programming, there are different methods to reach our goals depending on the situation.
>  Is the file plain text or binary? Is it reasonable to read the whole file before starting to process it? Should we create a new file or append to an existing one? And so on.
- [ ] For these operations we utilize the System.IO namespace and File Class methods.
- [ ]  Other useful classes for manipulating files and directories are `FileInfo`, `Directory`, `DirectoryInfo` and `Path`.
> In the next example, we ask the user to provide the file name to be read, retrieve the contents and then print everything on the screen. The user will be notified if the file does not exist. Let us provide some brief remarks.


```csharp
using System;
using System.IO;

class main{
    static void Main(string[] args)
    {
        string fileName ,Content;
        Console.Write("Filename to open: ");
        fileName = Console.ReadLine();
        if (File.Exists(fileName))
        {
            Content = File.ReadAllText(fileName);
            //Console.WriteLine("Content of the file:");
            Console.WriteLine(Content);
        }
        else
        {
            Console.WriteLine("File does not exist.");
        }
    }
}
```
- **Line 12:** `if (File.Exists(FileName))`
      - The `Exists` method from File the class is used to check if the file is present. The method returns true or false Boolean value.

- **Line 14:** `string content = File.ReadAllText(FileName);`
      - Again, using the File class and `ReadAllText` method, we get all the lines of the file which are returned.
Excellent! We're now entering the world of **File I/O (Input/Output)** —one of the most essential skills in real-world programming. Reading and writing files allows your programs to persist data, process large datasets, and interact with external systems.

### Table 1: Common `File` Class Methods

| Method | Description | Returns | Example |
| :--- | :--- | :--- | :--- |
| **`Exists(string path)`** | Checks if a file exists. | `bool` | `File.Exists("data.txt")` |
| **`ReadAllText(string path)`** | Reads the entire file as a string. | `string` | `string content = File.ReadAllText("data.txt");` |
| **`ReadAllLines(string path)`** | Reads all lines into a string array. | `string[]` | `string[] lines = File.ReadAllLines("data.txt");` |
| **`ReadLines(string path)`** | Reads lines lazily (returns `IEnumerable<string>`). | `IEnumerable<string>` | `foreach (string line in File.ReadLines("data.txt"))` |
| **`WriteAllText(string path, string contents)`** | Writes a string to a file (overwrites). | `void` | `File.WriteAllText("data.txt", "Hello World");` |
| **`WriteAllLines(string path, string[] contents)`** | Writes an array of strings to a file. | `void` | `File.WriteAllLines("data.txt", lines);` |
| **`AppendAllText(string path, string contents)`** | Appends text to the end of a file. | `void` | `File.AppendAllText("data.txt", "New line");` |
| **`Delete(string path)`** | Deletes the specified file. | `void` | `File.Delete("data.txt");` |
| **`Copy(string source, string dest)`** | Copies a file to a new location. | `void` | `File.Copy("source.txt", "dest.txt");` |
| **`Move(string source, string dest)`** | Moves a file to a new location. | `void` | `File.Move("source.txt", "newfolder/source.txt");` |
| **`GetCreationTime(string path)`** | Gets the creation date and time. | `DateTime` | `DateTime created = File.GetCreationTime("data.txt");` |
| **`GetLastWriteTime(string path)`** | Gets the last modified date and time. | `DateTime` | `DateTime modified = File.GetLastWriteTime("data.txt");` |

### 📋 Comparing Read Methods

| Method | Returns | Memory Usage | Best For |
| :--- | :--- | :--- | :--- |
| **`ReadAllText()`** | `string` (single string) | High (loads entire file) | Small files, processing entire content at once |
| **`ReadAllLines()`** | `string[]` (array of lines) | High (loads entire file) | Small to medium files, need to process line by line |
| **`ReadLines()`** | `IEnumerable<string>` (lazy enumeration) | Low (streams data) | **Large files**, processing one line at a time without loading everything |

### 🔍 Detailed Example: Reading Files with Different Methods

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string fileName = "example.txt";
        
        // 1. ReadAllText - reads entire file as one string
        Console.WriteLine("--- ReadAllText ---");
        if (File.Exists(fileName))
        {
            string content = File.ReadAllText(fileName);
            Console.WriteLine($"File size: {content.Length} characters");
            Console.WriteLine(content);
        }
        
        // 2. ReadAllLines - reads all lines into an array
        Console.WriteLine("\n--- ReadAllLines ---");
        if (File.Exists(fileName))
        {
            string[] lines = File.ReadAllLines(fileName);
            Console.WriteLine($"Number of lines: {lines.Length}");
            for (int i = 0; i < lines.Length; i++)
            {
                Console.WriteLine($"Line {i + 1}: {lines[i]}");
            }
        }
        
        // 3. ReadLines - lazy enumeration (best for large files)
        Console.WriteLine("\n--- ReadLines ---");
        if (File.Exists(fileName))
        {
            int lineCount = 0;
            foreach (string line in File.ReadLines(fileName))
            {
                lineCount++;
                if (lineCount <= 3) // Only show first 3 lines
                {
                    Console.WriteLine($"Line {lineCount}: {line}");
                }
                else
                {
                    Console.WriteLine($"... (and {lineCount - 3} more lines)");
                    break;
                }
            }
        }
    }
}
```

string fullPath = @"C:\Users\John\Documents\data.txt";

### 🔥 Writing to a File

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string fileName = "output.txt";
        string[] lines = {
            "Line 1: Hello World!",
            "Line 2: This is a test.",
            "Line 3: C# File I/O is powerful!"
        };
        
        // Write all lines to a file (overwrites if exists)
        File.WriteAllLines(fileName, lines);
        Console.WriteLine($"File '{fileName}' created with {lines.Length} lines.");
        
        // Append a line
        File.AppendAllText(fileName, "Line 4: Appended text!" + Environment.NewLine);
        Console.WriteLine("Appended a line.");
        
        // Read and display the file
        Console.WriteLine("\nFile contents:");
        string content = File.ReadAllText(fileName);
        Console.WriteLine(content);
        
        // Alternative: WriteAllText with a single string
        string text = "This is a single string written to a file.";
        File.WriteAllText("another.txt", text);
    }
}
```

### ⚠️ Error Handling and Best Practices

| Scenario | Recommended Practice | Code |
| :--- | :--- | :--- |
| **File doesn't exist** | Check with `File.Exists()` or use `try-catch`. | `if (File.Exists(path)) { ... }` |
| **File is locked/in use** | Use `try-catch` with `IOException`. | `try { File.ReadAllText(path); } catch (IOException) { }` |
| **Insufficient permissions** | Use `try-catch` with `UnauthorizedAccessException`. | `catch (UnauthorizedAccessException) { }` |
| **Path contains invalid characters** | Validate or use `Path.GetInvalidPathChars()`. | `if (path.IndexOfAny(Path.GetInvalidPathChars()) >= 0) { }` |
| **Disposing resources** | Use `using` statements for stream-based operations. | `using (StreamReader reader = new StreamReader(path)) { }` |

### 💡 Using `try-catch` for Robust File Operations

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        Console.Write("Enter the file name to read: ");
        string fileName = Console.ReadLine();

        try
        {
            // Check if the file exists
            if (!File.Exists(fileName))
            {
                Console.WriteLine($"File '{fileName}' not found!");
                return;
            }

            // Read the file
            string content = File.ReadAllText(fileName);
            Console.WriteLine($"File contents ({content.Length} characters):");
            Console.WriteLine(content);
        }
        catch (UnauthorizedAccessException)
        {
            Console.WriteLine("You don't have permission to read this file!");
        }
        catch (IOException ex)
        {
            Console.WriteLine($"An I/O error occurred: {ex.Message}");
        }
        catch (Exception ex)
        {
            Console.WriteLine($"An unexpected error occurred: {ex.Message}");
        }
    }
}
```

### 🔗 Connecting to Your Previous Programs

Here's how you could save and load your task list from earlier:

```csharp
using System;
using System.Collections.Generic;
using System.IO;

class Program
{
    static string filePath = "tasks.txt";
    static List<string> tasks = new List<string>();

    static void Main()
    {
        // Load tasks from file
        LoadTasks();
        
        // Main menu loop
        while (true)
        {
            Console.WriteLine("\n--- To-Do List ---");
            Console.WriteLine("1. Add task");
            Console.WriteLine("2. Remove task");
            Console.WriteLine("3. View tasks");
            Console.WriteLine("4. Exit and save");
            Console.Write("Choose: ");
            
            string choice = Console.ReadLine();
            
            switch (choice)
            {
                case "1":
                    Console.Write("Enter task: ");
                    tasks.Add(Console.ReadLine());
                    Console.WriteLine("Task added!");
                    break;
                case "2":
                    Console.Write("Enter task to remove: ");
                    if (tasks.Remove(Console.ReadLine()))
                        Console.WriteLine("Task removed!");
                    else
                        Console.WriteLine("Task not found!");
                    break;
                case "3":
                    if (tasks.Count == 0)
                        Console.WriteLine("No tasks!");
                    else
                        Console.WriteLine(string.Join("\n", tasks));
                    break;
                case "4":
                    SaveTasks();
                    Console.WriteLine("Tasks saved. Goodbye!");
                    return;
                default:
                    Console.WriteLine("Invalid option!");
                    break;
            }
        }
    }

    static void LoadTasks()
    {
        if (File.Exists(filePath))
        {
            tasks = new List<string>(File.ReadAllLines(filePath));
            Console.WriteLine($"Loaded {tasks.Count} tasks from {filePath}");
        }
        else
        {
            Console.WriteLine("No saved tasks found. Starting fresh.");
        }
    }

    static void SaveTasks()
    {
        File.WriteAllLines(filePath, tasks);
        Console.WriteLine($"Saved {tasks.Count} tasks to {filePath}");
    }
}
```

#### File vs FileInfo – When to Use Which

| Feature | `File` (Static) | `FileInfo` (Instance) |
| :--- | :--- | :--- |
| **Usage** | One-off operations | Multiple operations on the same file |
| **Performance** | Each call checks security | Security checked once |
| **Memory** | Less overhead | Slightly more overhead |
| **Convenience** | Simpler for single operations | Better for repeated operations |

```csharp
// Using File (static)
if (File.Exists("data.txt"))
{
    string content = File.ReadAllText("data.txt");
    File.Delete("data.txt");
}

// Using FileInfo (instance)
FileInfo file = new FileInfo("data.txt");
if (file.Exists)
{
    string content = File.ReadAllText(file.FullName);
    file.Delete();
}
```

#### Summary: The Golden Rules

| Rule | Explanation |
| :--- | :--- |
| **Check existence** | Use `File.Exists()` before reading to avoid exceptions. |
| **Use `using` statements** | For `StreamReader`/`StreamWriter` to ensure resources are released. |
| **Catch exceptions** | Always handle `IOException`, `UnauthorizedAccessException`, etc. |
| **Choose the right read method** | `ReadAllText` for small files, `ReadLines` for large files. |
| **Use `Path` class** | For combining and manipulating paths safely. |
| **Be careful with paths** | Use absolute or relative paths consistently. |
