#### Delete a file
- [ ] Deleting a file in C# is straightforward.
- [ ] A file can be deleted using the `File.Delete method`
- [ ] which is in the `System.IO namespace`.     
> he method takes only one argument which is the file name to be deleted (note: wildcard characters not supported). However, it is wise to consider that the action may not complete successfully, perhaps due file permissions.

> `Try-catch statement` should be used to handle the exception but that is left out to simplify the example. More on exception handling in chapter 9.


#### `File.Delete()` – Overview

| Aspect | Details |
| :--- | :--- |
| **Namespace** | `System.IO` |
| **Method** | `File.Delete(string path)` |
| **Behavior** | Deletes the specified file. If the file doesn't exist, **no exception is thrown**. |
| **Wildcards** | ❌ **Not supported** (you cannot use `*.txt`). |
| **Permissions** | Requires write permissions to the file and directory. |
| **Return Value** | `void` (nothing) |

#### Basic `File.Delete()` Example

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string fileName = "test.txt";

        // Check if the file exists before deleting
        if (File.Exists(fileName))
        {
            File.Delete(fileName);
            Console.WriteLine($"File '{fileName}' deleted successfully.");
        }
        else
        {
            Console.WriteLine($"File '{fileName}' does not exist.");
        }
    }
}
```

#### Table 1: `File.Delete()` – Important Behaviors

| Scenario | Behavior |
| :--- | :--- |
| **File exists and is not locked** | ✅ File is deleted |
| **File does not exist** | ✅ No exception thrown (silent success) |
| **File is read-only** | ❌ `UnauthorizedAccessException` |
| **File is in use by another process** | ❌ `IOException` |
| **Insufficient permissions** | ❌ `UnauthorizedAccessException` |
| **Invalid path (invalid characters)** | ❌ `ArgumentException` |
| **Directory doesn't exist** | ❌ `DirectoryNotFoundException` |

#### Comparison: `File.Delete()` vs Other Options

| Method | Purpose | Wildcards? | Returns |
| :--- | :--- | :--- | :--- |
| `File.Delete(path)` | Deletes a single file | ❌ No | `void` |
| `Directory.Delete(path)` | Deletes an empty directory | ❌ No | `void` |
| `Directory.Delete(path, true)` | Deletes directory and all contents | ❌ No | `void` |
| `Directory.GetFiles(path)` + loop | Delete multiple files with pattern matching | ❌ No (use `Directory.GetFiles` with search pattern) | `string[]` |

#### Complete Example with Error Handling

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        Console.Write("Enter the file name to delete: ");
        string fileName = Console.ReadLine();

        DeleteFileSafely(fileName);
    }

    static void DeleteFileSafely(string filePath)
    {
        try
        {
            // Check if the file exists
            if (!File.Exists(filePath))
            {
                Console.WriteLine($"File '{filePath}' does not exist.");
                return;
            }

            // Check if the file is read-only
            FileInfo fileInfo = new FileInfo(filePath);
            if (fileInfo.IsReadOnly)
            {
                Console.WriteLine($"File '{filePath}' is read-only. Removing read-only attribute...");
                fileInfo.IsReadOnly = false;
            }

            // Delete the file
            File.Delete(filePath);
            Console.WriteLine($"File '{filePath}' deleted successfully.");
        }
        catch (DirectoryNotFoundException ex)
        {
            Console.WriteLine($"Directory not found: {ex.Message}");
        }
        catch (UnauthorizedAccessException ex)
        {
            Console.WriteLine($"Access denied: {ex.Message}");
        }
        catch (IOException ex)
        {
            Console.WriteLine($"I/O error (file may be in use): {ex.Message}");
        }
        catch (Exception ex)
        {
            Console.WriteLine($"Unexpected error: {ex.Message}");
        }
    }
}
```

#### Deleting Multiple Files with a Pattern

Since `File.Delete()` doesn't support wildcards, here's how to delete files matching a pattern:

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string directoryPath = @"C:\Temp";
        string searchPattern = "*.tmp"; // Delete all .tmp files

        // Get all files matching the pattern
        string[] files = Directory.GetFiles(directoryPath, searchPattern);

        if (files.Length == 0)
        {
            Console.WriteLine($"No files matching '{searchPattern}' found in '{directoryPath}'.");
            return;
        }

        Console.WriteLine($"Found {files.Length} files matching '{searchPattern}'.");

        // Delete each file
        foreach (string file in files)
        {
            try
            {
                File.Delete(file);
                Console.WriteLine($"Deleted: {Path.GetFileName(file)}");
            }
            catch (Exception ex)
            {
                Console.WriteLine($"Failed to delete {Path.GetFileName(file)}: {ex.Message}");
            }
        }

        Console.WriteLine("Deletion process completed.");
    }
}
```

#### Deleting Directories

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string directoryPath = @"C:\Temp\MyFolder";

        // Delete an empty directory
        if (Directory.Exists(directoryPath))
        {
            try
            {
                Directory.Delete(directoryPath);
                Console.WriteLine($"Directory '{directoryPath}' deleted.");
            }
            catch (IOException)
            {
                Console.WriteLine($"Directory is not empty. Delete with recursive flag.");
                // Delete recursively (deletes all files and subdirectories)
                Directory.Delete(directoryPath, true);
                Console.WriteLine($"Directory '{directoryPath}' deleted with all contents.");
            }
        }
        else
        {
            Console.WriteLine($"Directory '{directoryPath}' does not exist.");
        }
    }
}
```

#### Important: Deleting Files Used by Your Program

You cannot delete a file that your program is currently using. Always close the file first:

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string filePath = "data.txt";

        // Writing to the file
        using (StreamWriter writer = new StreamWriter(filePath))
        {
            writer.WriteLine("Hello, World!");
        } // File is closed here

        // Now we can delete it
        try
        {
            File.Delete(filePath);
            Console.WriteLine("File deleted successfully.");
        }
        catch (Exception ex)
        {
            Console.WriteLine($"Error: {ex.Message}");
        }
    }
}
```

#### Safe Deletion with Confirmation

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string fileName = "important.txt";

        if (!File.Exists(fileName))
        {
            Console.WriteLine($"File '{fileName}' does not exist.");
            return;
        }

        // Display file information
        FileInfo info = new FileInfo(fileName);
        Console.WriteLine($"File: {fileName}");
        Console.WriteLine($"Size: {info.Length} bytes");
        Console.WriteLine($"Created: {info.CreationTime}");
        Console.WriteLine($"Modified: {info.LastWriteTime}");

        // Ask for confirmation
        Console.Write("Are you sure you want to delete this file? (y/n): ");
        string response = Console.ReadLine();

        if (response?.ToLower() == "y")
        {
            try
            {
                File.Delete(fileName);
                Console.WriteLine("File deleted successfully.");
            }
            catch (Exception ex)
            {
                Console.WriteLine($"Error: {ex.Message}");
            }
        }
        else
        {
            Console.WriteLine("Deletion cancelled.");
        }
    }
}
```

#### Summary: The Golden Rules

| Rule | Explanation |
| :--- | :--- |
| **Check existence** | Use `File.Exists()` to avoid potential confusion (though not required). |
| **Handle exceptions** | Always use `try-catch` for file operations. |
| **Close files first** | Ensure any streams are closed (`using` statement) before deleting. |
| **No wildcards** | Use `Directory.GetFiles()` with a search pattern for wildcard deletions. |
| **Check permissions** | `File.Delete()` throws `UnauthorizedAccessException` if you don't have permissions. |
| **Use confirmation** | For important files, ask the user to confirm deletion. |
