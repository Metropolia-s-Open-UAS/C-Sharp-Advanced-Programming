#### Append to a file
- Appending to an existing file is comparable to writing to a file:
>`StreamWriter` constructor arguments include the `filename` and Boolean value “true“ to indicate that we want to append to the related file. If the file does not exist it will be created. The using statement encloses the file operations and takes care of the garbage collection – you do not have to take care of releasing the used memory, C# is doing that for you.

#### Appending vs Overwriting – The Key Difference

| Behavior | `StreamWriter` Constructor | Result |
| :--- | :--- | :--- |
| **Overwrite (Default)** | `new StreamWriter(filename)` | File is created or **completely replaced** |
| **Append** | `new StreamWriter(filename, true)` | Content is **added to the end** of the file |

#### Basic Append Example (Based on Your Description)

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string fileName = "log.txt";
        string content = $"Log entry at {DateTime.Now}: Application started\n";

        // Append to the file
        using (StreamWriter writer = new StreamWriter(fileName, true))
        {
            writer.Write(content);
        }

        Console.WriteLine($"Appended to {fileName}");

        // Read and display the file
        Console.WriteLine("\nCurrent file contents:");
        Console.WriteLine(File.ReadAllText(fileName));
    }
}
```

#### Table 1: `StreamWriter` Constructor Options

| Constructor | Behavior | When to Use |
| :--- | :--- | :--- |
| `new StreamWriter(filename)` | Overwrites (truncates) the file. | Creating new files, replacing old data. |
| `new StreamWriter(filename, false)` | Same as above (false is default). | Explicitly indicating overwrite. |
| `new StreamWriter(filename, true)` | **Appends** to the file. | Adding to existing files (logs, accumulations). |
| `new StreamWriter(filename, true, encoding)` | Appends with a specific encoding. | When you need a specific character encoding (e.g., UTF-8). |

#### Step-by-Step Example: Multiple Appends

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string filePath = "data.txt";

        // First run: Creates the file with initial content
        using (StreamWriter writer = new StreamWriter(filePath, true))
        {
            writer.WriteLine("--- Start of file ---");
        }

        // Second run: Appends more content
        using (StreamWriter writer = new StreamWriter(filePath, true))
        {
            writer.WriteLine("Entry 1: User logged in");
        }

        // Third run: Appends more content
        using (StreamWriter writer = new StreamWriter(filePath, true))
        {
            writer.WriteLine("Entry 2: User performed action");
            writer.WriteLine("--- End of file ---");
        }

        // Display the final content
        Console.WriteLine(File.ReadAllText(filePath));
    }
}
```

**Output:**
```
--- Start of file ---
Entry 1: User logged in
Entry 2: User performed action
--- End of file ---
```

#### Using `File.AppendAllText()` – The Simpler Way

For simple appends, `File.AppendAllText()` is more concise:

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string filePath = "log.txt";

        // Append text (creates file if it doesn't exist)
        File.AppendAllText(filePath, $"Log at {DateTime.Now}: Application started\n");
        File.AppendAllText(filePath, $"Log at {DateTime.Now}: Loading configuration\n");
        File.AppendAllText(filePath, $"Log at {DateTime.Now}: Application ready\n");

        Console.WriteLine(File.ReadAllText(filePath));
    }
}
```

#### Comparing Append Methods

| Method | Creates File if Missing | Appends | Adds Newline? | Best For |
| :--- | :--- | :--- | :--- | :--- |
| `StreamWriter(path, true).Write()` | ✅ Yes | ✅ Yes | ❌ No | Adding text without a newline |
| `StreamWriter(path, true).WriteLine()` | ✅ Yes | ✅ Yes | ✅ Yes | Adding full lines |
| `File.AppendAllText(path, text)` | ✅ Yes | ✅ Yes | ❌ No (include `\n` manually) | Simple appends |
| `File.AppendAllLines(path, lines)` | ✅ Yes | ✅ Yes | ✅ Yes | Appending arrays of lines |

#### Complete Logging System with Appending

Here's a practical example showing why appending is so valuable:

```csharp
using System;
using System.IO;

class LogManager
{
    private string logFilePath;

    public LogManager(string filePath)
    {
        logFilePath = filePath;
        EnsureDirectoryExists();
    }

    private void EnsureDirectoryExists()
    {
        string directory = Path.GetDirectoryName(logFilePath);
        if (!string.IsNullOrEmpty(directory) && !Directory.Exists(directory))
        {
            Directory.CreateDirectory(directory);
        }
    }

    public void WriteLog(string message, string level = "INFO")
    {
        string timestamp = DateTime.Now.ToString("yyyy-MM-dd HH:mm:ss");
        string logEntry = $"[{timestamp}] {level}: {message}";

        // Append to the log file (creates file if it doesn't exist)
        using (StreamWriter writer = new StreamWriter(logFilePath, true))
        {
            writer.WriteLine(logEntry);
        }
    }

    public void Info(string message) => WriteLog(message, "INFO");
    public void Warning(string message) => WriteLog(message, "WARNING");
    public void Error(string message) => WriteLog(message, "ERROR");
}

class Program
{
    static void Main()
    {
        LogManager logger = new LogManager("application.log");

        Console.WriteLine("--- Simulating Application ---");
        
        logger.Info("Application started");
        logger.Info("Loading configuration...");
        
        try
        {
            // Simulate some work
            Console.Write("Enter a number: ");
            string input = Console.ReadLine();
            int number = int.Parse(input);
            
            logger.Info($"User entered: {number}");
            
            if (number < 0)
            {
                logger.Warning("Negative number entered");
            }
            
            int result = 100 / number; // May cause error if number is 0
            logger.Info($"Calculation result: {result}");
        }
        catch (DivideByZeroException ex)
        {
            logger.Error($"Division by zero: {ex.Message}");
            Console.WriteLine("Error: Cannot divide by zero!");
        }
        catch (FormatException ex)
        {
            logger.Error($"Invalid input format: {ex.Message}");
            Console.WriteLine("Error: Please enter a valid number!");
        }
        finally
        {
            logger.Info("Application ended");
        }

        Console.WriteLine("\n--- Log File Contents ---");
        Console.WriteLine(File.ReadAllText("application.log"));
    }
}
```

**Sample Log File:**
```
[2024-01-15 14:30:25] INFO: Application started
[2024-01-15 14:30:25] INFO: Loading configuration...
[2024-01-15 14:30:30] INFO: User entered: 5
[2024-01-15 14:30:30] INFO: Calculation result: 20
[2024-01-15 14:30:30] INFO: Application ended
```

#### Important Notes from Your Description

| Note | Explanation |
| :--- | :--- |
| **Filename + true** | The `true` parameter in `new StreamWriter(filename, true)` enables append mode. |
| **Creates if missing** | If the file doesn't exist, `StreamWriter` with `true` will **create** it automatically. |
| **Garbage Collection** | C# handles memory management, but `using` ensures the file is closed **immediately** (not just when GC runs). |

> **Important Clarification:** 
> The `using` statement handles **resource management**, not garbage collection. It calls `Dispose()` immediately, which closes the file. Garbage collection is for **memory** cleanup, not file handles. Without `using`, the file might stay locked until GC runs (which could be minutes or never, causing errors).

#### Error Handling with Append

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string filePath = "output.txt";
        string data = "This data will be appended.";

        try
        {
            using (StreamWriter writer = new StreamWriter(filePath, true))
            {
                writer.WriteLine(data);
            }
            Console.WriteLine($"Data appended to {filePath}");
        }
        catch (DirectoryNotFoundException ex)
        {
            Console.WriteLine($"Directory not found: {ex.Message}");
        }
        catch (UnauthorizedAccessException ex)
        {
            Console.WriteLine($"Access denied: {ex.Message}");
        }
        catch (IOException ex)
        {
            Console.WriteLine($"I/O error: {ex.Message}");
        }
        catch (Exception ex)
        {
            Console.WriteLine($"Unexpected error: {ex.Message}");
        }
    }
}
```

#### Advanced: Appending with Different Encodings

```csharp
using System.IO;
using System.Text;

// Append with UTF-8 encoding (default)
using (StreamWriter writer = new StreamWriter("file.txt", true))
{
    writer.WriteLine("Hello, World!");
}

// Append with UTF-16 (Unicode) encoding
using (StreamWriter writer = new StreamWriter("file.txt", true, Encoding.Unicode))
{
    writer.WriteLine("Hello, World!");
}

// Append with UTF-8 without BOM
using (StreamWriter writer = new StreamWriter("file.txt", true, new UTF8Encoding(false)))
{
    writer.WriteLine("Hello, World!");
}
```

#### Summary: The Golden Rules

| Rule | Explanation |
| :--- | :--- |
| **Use `true` for append** | `new StreamWriter(path, true)` adds to the end. |
| **Default is overwrite** | `new StreamWriter(path)` or `new StreamWriter(path, false)` replaces content. |
| **Always use `using`** | Ensures the file is closed and resources are released. |
| **File is auto-created** | If the file doesn't exist, both overwrite and append modes will create it. |
| **`File.AppendAllText()` is simpler** | Use this for quick appends without needing `StreamWriter`. |
