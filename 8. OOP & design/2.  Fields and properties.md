#### Fields and properties
- **Fields** are basically variables which are declared inside a `class` or a `struct`.
- They function exactly the same as any other variables, except access modifiers play a significant role on determining who can read and modify information.
- A `field` can be `public`, `private`, `(private)` `protected` or `(protected)` internal.
```csharp
class Building
{
    // private field
    private string color;

    // public field
    public int doorCount;
}
```
- **Properties** provide a mechanism to access (read, write) private fields by other classes while hiding the implementation.
- Properties include special `methods` called `accessors` which can include `accessor code` for different purposes like manipulating the value(s) or checking the validity of a new value.
-  A `get` property returns value(s) while a `set` property is used to assign a new value.
> Simple properties which do not require any custom accessor code can be implemented as expression body definition or as auto-implemented properties as in the following example. Note that the accessors follow PascalCase naming convention.
```csharp
class Building
{
   protected string Name { get; set; }
   protected int Year { get; set; }

   public Building (string name, int year)
   {
      this.Name = name;
      this.Year = year;
   } 
}
```


#### Fields vs Properties – The Big Picture

| Aspect | Field | Property |
| :--- | :--- | :--- |
| **Definition** | A variable declared directly in a class. | A member that provides controlled access to a field. |
| **Access** | Direct read/write (if `public`). | Controlled via `get` and `set` accessors. |
| **Encapsulation** | ❌ Limited (if public, any code can change it). | ✅ Full control (can validate, compute, or log). |
| **Flexibility** | ❌ Rigid (just stores data). | ✅ Flexible (can add logic without breaking existing code). |
| **Data Validation** | ❌ Cannot validate values. | ✅ Can validate in `set` accessor. |
| **Computed Values** | ❌ Cannot compute on the fly. | ✅ Can return computed values in `get`. |
| **Binding** | ❌ Not supported (Windows Forms, WPF). | ✅ Supports data binding. |

#### Property Types in C#

| Property Type | Syntax | Description | Use Case |
| :--- | :--- | :--- | :--- |
| **Full Property** | `private int _age;` <br> `public int Age { get { return _age; } set { _age = value; } }` | Full control with custom logic. | When you need to validate or compute values. |
| **Auto-Implemented Property** | `public int Age { get; set; }` | Compiler generates a hidden field. | When you don't need custom logic. |
| **Read-Only Property** | `public int Age { get; }` | Can only be set in the constructor. | When the value should never change after creation. |
| **Write-Only Property** | `public int Age { set; }` (rare) | Can only be set, not read. | For security-sensitive data (rarely used). |
| **Expression-Bodied Property** | `public int Age => DateTime.Now.Year - _birthYear;` | Compact syntax for computed properties. | When the value can be computed. |

#### The Evolution of Property Syntax

```csharp
using System;

class Building
{
    // ========== 1. Private Field with Manual Properties ==========
    private string _name;
    private int _year;

    // Manual property - older syntax
    public string Name
    {
        get { return _name; }
        set { _name = value; }
    }

    // Manual property with validation
    public int Year
    {
        get { return _year; }
        set 
        { 
            if (value < 0)
                throw new ArgumentException("Year cannot be negative!");
            _year = value; 
        }
    }

    // ========== 2. Auto-Implemented Properties ==========
    // Introduced in C# 3.0 - the compiler creates the hidden field
    public string Address { get; set; }
    public int DoorCount { get; set; }

    // ========== 3. Expression-Bodied Properties ==========
    // Introduced in C# 6.0 and 7.0
    public int YearBuilt { get; set; }
    
    // Expression-bodied getter (C# 6.0)
    public int Age => DateTime.Now.Year - YearBuilt;
    
    // Expression-bodied constructor (C# 7.0)
    public Building(string name, int year) => (Name, YearBuilt) = (name, year);
    
    // Expression-bodied method (C# 6.0)
    public string GetInfo() => $"Building: {Name}, Year: {YearBuilt}";
}
```

#### Deep Dive: Full Property with Validation

```csharp
using System;

class Building
{
    private int _floorCount;

    public int FloorCount
    {
        get { return _floorCount; }
        set
        {
            // Validation
            if (value <= 0)
            {
                throw new ArgumentException("Floor count must be positive!");
            }
            if (value > 100)
            {
                Console.WriteLine("Warning: Very tall building!");
            }
            _floorCount = value;
        }
    }

    private string _color;

    public string Color
    {
        get { return _color; }
        set
        {
            // Could be a real check here
            if (string.IsNullOrEmpty(value))
            {
                _color = "White"; // Default color
            }
            else
            {
                _color = value;
            }
        }
    }

    // Read-only property (can only be set in constructor)
    public string Name { get; }

    public Building(string name)
    {
        Name = name;
        _floorCount = 1;
        _color = "White";
    }
}

class Program
{
    static void Main()
    {
        Building b = new Building("Sky Tower");
        
        b.FloorCount = 50;  // Works fine
        Console.WriteLine($"Floors: {b.FloorCount}");

        // b.FloorCount = -5; // Throws ArgumentException!
    }
}
```

#### Access Modifiers for Properties

| Scenario | Syntax | Explanation |
| :--- | :--- | :--- |
| **Public get + set** | `public string Name { get; set; }` | Anyone can read or write. |
| **Public get, private set** | `public string Name { get; private set; }` | Anyone can read, only the class can set. |
| **Public get, protected set** | `public string Name { get; protected set; }` | Anyone can read, derived classes can set. |
| **Public get, init** | `public string Name { get; init; }` | Can only be set during object initialization (C# 9.0+). |
| **Private get, public set** | `public string Name { private get; set; }` | Anyone can write, only the class can read (rare). |

#### Complete Example: Building Class with Fields and Properties

```csharp
using System;

public class Building
{
    // ============ PRIVATE FIELDS ============
    private string _id;
    private int _doorCount;
    private double _leasableArea;
    private bool _isOccupied;

    // ============ PUBLIC PROPERTIES ============

    // Read-only (set in constructor only)
    public string Id => _id;

    // Auto-implemented with private set
    public string Name { get; private set; }
    public int YearBuilt { get; private set; }

    // Full property with validation
    public int DoorCount
    {
        get { return _doorCount; }
        set
        {
            if (value < 0)
                throw new ArgumentException("Door count cannot be negative!");
            _doorCount = value;
        }
    }

    // Property with calculated value
    public string BuildingType
    {
        get
        {
            if (_doorCount <= 1) return "Small building";
            if (_doorCount <= 5) return "Medium building";
            if (_doorCount <= 20) return "Large building";
            return "Very large building";
        }
    }

    // Computed property (read-only)
    public int Age => DateTime.Now.Year - YearBuilt;

    // Property with validation and side effects
    public bool IsOccupied
    {
        get { return _isOccupied; }
        set
        {
            if (_isOccupied != value)
            {
                _isOccupied = value;
                Console.WriteLine($"Building '{Name}' is now {(value ? "occupied" : "vacant")}.");
            }
        }
    }

    // ============ CONSTRUCTORS ============

    // Constructor with validation
    public Building(string id, string name, int yearBuilt, int doorCount, double leasableArea)
    {
        if (string.IsNullOrEmpty(id))
            throw new ArgumentException("ID cannot be null or empty!");

        if (string.IsNullOrEmpty(name))
            throw new ArgumentException("Name cannot be null or empty!");

        if (yearBuilt > DateTime.Now.Year)
            throw new ArgumentException("Year cannot be in the future!");

        _id = id;
        Name = name;
        YearBuilt = yearBuilt;
        DoorCount = doorCount;
        _leasableArea = leasableArea;
        _isOccupied = false;
    }

    // ============ METHODS ============

    public void DisplayInfo()
    {
        Console.WriteLine("═══════════════════════════════");
        Console.WriteLine($"ID:                {_id}");
        Console.WriteLine($"Name:              {Name}");
        Console.WriteLine($"Year Built:        {YearBuilt}");
        Console.WriteLine($"Age:               {Age} years");
        Console.WriteLine($"Door Count:        {_doorCount}");
        Console.WriteLine($"Leasable Area:     {_leasableArea} sqm");
        Console.WriteLine($"Type:              {BuildingType}");
        Console.WriteLine($"Occupied:          {(_isOccupied ? "Yes" : "No")}");
        Console.WriteLine("═══════════════════════════════");
        Console.WriteLine();
    }

    public void ToggleOccupancy()
    {
        IsOccupied = !IsOccupied;
    }
}

class Program
{
    static void Main()
    {
        // Create a building
        Building b1 = new Building(
            id: "B-001",
            name: "Sky Tower",
            yearBuilt: 2020,
            doorCount: 25,
            leasableArea: 4500.5
        );

        b1.DisplayInfo();

        // Use property with validation
        b1.DoorCount = 30;
        Console.WriteLine($"Updated door count: {b1.DoorCount}");

        // Toggle occupancy (will trigger the console message)
        b1.ToggleOccupancy();
        b1.ToggleOccupancy();

        // Try to create a building with validation (this will throw)
        try
        {
            Building b2 = new Building("", "Bad Building", 2025, 5, 100);
        }
        catch (Exception ex)
        {
            Console.WriteLine($"\nError creating building: {ex.Message}");
        }
    }
}
```

#### When to Use Each Property Type

| Scenario | Recommended Property Type | Example |
| :--- | :--- | :--- |
| Simple data storage | Auto-implemented property | `public string Name { get; set; }` |
| Immutable object (set once) | Read-only property | `public string Id { get; }` |
| Set once at creation | `init` accessor (C# 9.0+) | `public string Name { get; init; }` |
| Need validation | Full property | `public int Age { get { ... } set { ... } }` |
| Computed value | Expression-bodied property | `public int Age => DateTime.Now.Year - BirthYear;` |
| Must not be changed externally | `private set` | `public string Name { get; private set; }` |
| Logging or side effects | Full property | `set { _field = value; LogChange(); }` |

#### Common Mistakes and Best Practices

| ❌ Bad Practice | ✅ Good Practice | Why |
| :--- | :--- | :--- |
| `public int age;` (public field) | `public int Age { get; set; }` (public property) | Properties provide encapsulation and future flexibility. |
| `public string Name { get; set; }` without validation | Full property with validation in `set` | Validate data to ensure object consistency. |
| Exposing private fields directly | Use properties to control access | Prevents external code from breaking encapsulation. |
| Using auto-properties for computed values | Use expression-bodied properties | Auto-properties can't compute values. |
| Not using `private` for internal state | Always use `private` fields with public properties | Maintains encapsulation. |


| Rule | Explanation |
| :--- | :--- |
| **Use properties, not public fields** | Properties provide encapsulation and flexibility. |
| **Use auto-implemented properties** | For simple data storage without validation. |
| **Use full properties** | When you need validation, logging, or computed values. |
| **Use `private set` or `init`** | For read-only or immutable properties. |
| **PascalCase for properties** | `Name`, `Age`, `FloorCount` (not `name`, `age`). |
| **Don't expose internal fields** | Keep fields `private` and use properties to expose them. |
