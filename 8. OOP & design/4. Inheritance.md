#### Inheritance 
- Inheritance is an operation which allows creation of a new class from an existing base class and by doing so to reuse, extend and modify the behaviour of the base class.
-  In general, the derived class is a specialization of the base class. For example, we could re-use the Building class introduced earlier in this chapter to introduce a derived class CommercialBuilding, which could include special methods only applicaple for a commercial building. The syntax of inheritance is as follows:
```csharp
<access_modifier> class <base_class_name>
{
      // base class implementation
}

<access_modifier> class <derived_class_name> : <base_class_name>
{
     // derived class implementation
}
```

#### Inheritance – Key Concepts

| Concept | Definition | Example |
| :--- | :--- | :--- |
| **Base Class (Parent)** | The class being inherited from. | `Building` |
| **Derived Class (Child)** | The class that inherits from the base class. | `CommercialBuilding : Building` |
| **"Is-A" Relationship** | The derived class **is a** specialized version of the base class. | A `CommercialBuilding` **is a** `Building`. |
| **Reuse** | Derived classes automatically have all members of the base class. | `CommercialBuilding` has `Name`, `YearBuilt`, etc. |
| **Extension** | Derived classes can add new members. | `CommercialBuilding` adds `LeaseRate` and `GetRevenue()`. |
| **Modification** | Derived classes can override base class methods. | Override `DisplayInfo()` for commercial buildings. |

#### Basic Inheritance Example

```csharp
using System;

// ============ BASE CLASS ============
public class Building
{
    // Fields
    protected string Name;
    protected int YearBuilt;
    protected int DoorCount;

    // Constructor
    public Building(string name, int yearBuilt, int doorCount)
    {
        Name = name;
        YearBuilt = yearBuilt;
        DoorCount = doorCount;
        Console.WriteLine($"Building constructor called for: {Name}");
    }

    // Method
    public virtual void DisplayInfo()
    {
        Console.WriteLine("═══════════════════════════════");
        Console.WriteLine($"Building: {Name}");
        Console.WriteLine($"  Year Built: {YearBuilt}");
        Console.WriteLine($"  Door Count: {DoorCount}");
        Console.WriteLine("═══════════════════════════════");
    }

    public int GetAge()
    {
        return DateTime.Now.Year - YearBuilt;
    }
}

// ============ DERIVED CLASS ============
public class CommercialBuilding : Building
{
    // Additional fields
    private double LeaseRate;
    private double LeasableArea;

    // Constructor - calls base class constructor using 'base'
    public CommercialBuilding(string name, int yearBuilt, int doorCount, 
                              double leaseRate, double leasableArea)
        : base(name, yearBuilt, doorCount)
    {
        LeaseRate = leaseRate;
        LeasableArea = leasableArea;
        Console.WriteLine($"CommercialBuilding constructor called for: {Name}");
    }

    // New method specific to CommercialBuilding
    public double CalculateMonthlyRevenue()
    {
        return LeaseRate * LeasableArea;
    }

    // Override base method
    public override void DisplayInfo()
    {
        Console.WriteLine("═══════════════════════════════");
        Console.WriteLine($"Commercial Building: {Name}");
        Console.WriteLine($"  Year Built: {YearBuilt}");
        Console.WriteLine($"  Door Count: {DoorCount}");
        Console.WriteLine($"  Lease Rate: ${LeaseRate:F2}/sqm");
        Console.WriteLine($"  Leasable Area: {LeasableArea} sqm");
        Console.WriteLine($"  Monthly Revenue: ${CalculateMonthlyRevenue():F2}");
        Console.WriteLine("═══════════════════════════════");
    }
}

// ============ PROGRAM ============
class Program
{
    static void Main()
    {
        Console.WriteLine("=== Inheritance Demo ===\n");

        // Create a base class object
        Building b1 = new Building("Community Hall", 2010, 4);
        b1.DisplayInfo();

        Console.WriteLine();

        // Create a derived class object
        CommercialBuilding cb1 = new CommercialBuilding(
            "Sky Tower", 2020, 25, 45.50, 2500.75
        );
        cb1.DisplayInfo();

        Console.WriteLine();
        Console.WriteLine($"Building age: {cb1.GetAge()} years");
        Console.WriteLine($"Monthly revenue: ${cb1.CalculateMonthlyRevenue():F2}");
    }
}
```

**Output:**
```
=== Inheritance Demo ===

Building constructor called for: Community Hall
═══════════════════════════════
Building: Community Hall
  Year Built: 2010
  Door Count: 4
═══════════════════════════════

Building constructor called for: Sky Tower
CommercialBuilding constructor called for: Sky Tower
═══════════════════════════════
Commercial Building: Sky Tower
  Year Built: 2020
  Door Count: 25
  Lease Rate: $45.50/sqm
  Leasable Area: 2500.75 sqm
  Monthly Revenue: $113784.13
═══════════════════════════════

Building age: 4 years
Monthly revenue: $113784.13
```

#### Inheritance Syntax Breakdown

| Syntax Element | Description | Example |
| :--- | :--- | :--- |
| **Base Class** | The class being inherited from. | `public class Building` |
| **Derived Class** | The class that inherits. | `public class CommercialBuilding` |
| **`:` (colon)** | Indicates inheritance. | `CommercialBuilding : Building` |
| **`base` keyword** | Refers to the base class. | `base(name, yearBuilt, doorCount)` |
| **`virtual` keyword** | Allows a method to be overridden. | `public virtual void DisplayInfo()` |
| **`override` keyword** | Overrides a base class method. | `public override void DisplayInfo()` |

#### Inheritance Hierarchy – Access Modifiers

| Access Modifier | Accessible in Base Class | Accessible in Derived Class | Accessible Outside |
| :--- | :--- | :--- | :--- |
| **`public`** | ✅ Yes | ✅ Yes | ✅ Yes |
| **`protected`** | ✅ Yes | ✅ Yes | ❌ No |
| **`private`** | ✅ Yes | ❌ No | ❌ No |
| **`internal`** | ✅ Yes | ✅ Yes (same assembly) | ❌ No |
| **`protected internal`** | ✅ Yes | ✅ Yes (same assembly or derived) | ❌ No |

```csharp
class Building
{
    public string PublicField = "Everyone can see me.";
    protected string ProtectedField = "Only derived classes can see me.";
    private string PrivateField = "Only Building can see me.";
}

class CommercialBuilding : Building
{
    public void TestAccess()
    {
        Console.WriteLine(PublicField);     // ✅ Works
        Console.WriteLine(ProtectedField);  // ✅ Works
        // Console.WriteLine(PrivateField); // ❌ Compiler error!
    }
}
```

#### Method Overriding with `virtual` and `override`

```csharp
using System;

class Animal
{
    // Virtual method - can be overridden
    public virtual void MakeSound()
    {
        Console.WriteLine("Animal makes a sound.");
    }

    // Virtual method with default behavior
    public virtual void Move()
    {
        Console.WriteLine("Animal moves.");
    }

    // Non-virtual method - cannot be overridden
    public void Eat()
    {
        Console.WriteLine("Animal eats.");
    }
}

class Dog : Animal
{
    // Override base method
    public override void MakeSound()
    {
        Console.WriteLine("Woof! Woof!");
    }

    // Override with different behavior
    public override void Move()
    {
        Console.WriteLine("Dog runs on four legs.");
    }

    // New method specific to Dog
    public void Fetch()
    {
        Console.WriteLine("Dog fetches the ball.");
    }
}

class Cat : Animal
{
    public override void MakeSound()
    {
        Console.WriteLine("Meow! Meow!");
    }

    public override void Move()
    {
        Console.WriteLine("Cat walks on four legs.");
    }

    public void Climb()
    {
        Console.WriteLine("Cat climbs a tree.");
    }
}

class Program
{
    static void Main()
    {
        Console.WriteLine("=== Animal Demo ===\n");

        Animal animal = new Animal();
        animal.MakeSound();  // Animal makes a sound.

        Dog dog = new Dog();
        dog.MakeSound();     // Woof! Woof!
        dog.Move();          // Dog runs on four legs.
        dog.Eat();           // Animal eats. (Inherited)
        dog.Fetch();         // Dog fetches the ball.

        Console.WriteLine();

        Cat cat = new Cat();
        cat.MakeSound();     // Meow! Meow!
        cat.Move();          // Cat walks on four legs.
        cat.Climb();         // Cat climbs a tree.

        Console.WriteLine("\n=== Polymorphism Demo ===\n");

        // Polymorphism: Treat derived classes as base class
        Animal[] animals = new Animal[]
        {
            new Dog(),
            new Cat(),
            new Animal()
        };

        foreach (Animal a in animals)
        {
            a.MakeSound();  // Calls the appropriate override
            a.Move();       // Calls the appropriate override
            Console.WriteLine();
        }
    }
}
```

**Output:**
```
=== Animal Demo ===

Animal makes a sound.
Woof! Woof!
Dog runs on four legs.
Animal eats.
Dog fetches the ball.

Meow! Meow!
Cat walks on four legs.
Cat climbs a tree.

=== Polymorphism Demo ===

Woof! Woof!
Dog runs on four legs.

Meow! Meow!
Cat walks on four legs.

Animal makes a sound.
Animal moves.
```

#### `virtual`, `override`, `abstract`, and `new` Keywords

| Keyword | Purpose | Usage |
| :--- | :--- | :--- |
| **`virtual`** | Marks a method that can be overridden. | Base class methods. |
| **`override`** | Overrides a virtual method. | Derived class methods. |
| **`abstract`** | Method has no implementation; must be overridden. | Abstract base classes. |
| **`new`** | Hides the base class method (not recommended). | Rarely used; avoid hiding. |
| **`sealed`** | Prevents further overriding. | Applied to an `override` method. |

#### Inheritance Hierarchy – Multiple Levels

```csharp
using System;

// ============ LEVEL 1 ============
class Building
{
    public string Name { get; set; }
    public int YearBuilt { get; set; }

    public Building(string name, int yearBuilt)
    {
        Name = name;
        YearBuilt = yearBuilt;
        Console.WriteLine($"Building constructor: {Name}");
    }

    public virtual void DisplayInfo()
    {
        Console.WriteLine($"Building: {Name}, Year: {YearBuilt}");
    }
}

// ============ LEVEL 2 ============
class CommercialBuilding : Building
{
    public double LeaseRate { get; set; }

    public CommercialBuilding(string name, int yearBuilt, double leaseRate)
        : base(name, yearBuilt)
    {
        LeaseRate = leaseRate;
        Console.WriteLine($"CommercialBuilding constructor: {Name}");
    }

    public override void DisplayInfo()
    {
        Console.WriteLine($"Commercial Building: {Name}, Year: {YearBuilt}, Rate: ${LeaseRate}/sqm");
    }
}

// ============ LEVEL 3 ============
class OfficeBuilding : CommercialBuilding
{
    public int NumberOfOffices { get; set; }

    public OfficeBuilding(string name, int yearBuilt, double leaseRate, int offices)
        : base(name, yearBuilt, leaseRate)
    {
        NumberOfOffices = offices;
        Console.WriteLine($"OfficeBuilding constructor: {Name}");
    }

    public override void DisplayInfo()
    {
        Console.WriteLine($"Office Building: {Name}, Year: {YearBuilt}, Offices: {NumberOfOffices}, Rate: ${LeaseRate}/sqm");
    }

    public void PrintOfficeDetails()
    {
        Console.WriteLine($"  Number of offices: {NumberOfOffices}");
        Console.WriteLine($"  Average size per office: 100 sqm");
    }
}

class Program
{
    static void Main()
    {
        Console.WriteLine("=== Multi-level Inheritance ===\n");

        OfficeBuilding office = new OfficeBuilding("Tech Plaza", 2020, 45.50, 50);
        Console.WriteLine();

        office.DisplayInfo();
        office.PrintOfficeDetails();
    }
}
```

**Output:**
```
=== Multi-level Inheritance ===

Building constructor: Tech Plaza
CommercialBuilding constructor: Tech Plaza
OfficeBuilding constructor: Tech Plaza

Office Building: Tech Plaza, Year: 2020, Offices: 50, Rate: $45.5/sqm
  Number of offices: 50
  Average size per office: 100 sqm
```

#### `base` Keyword Usage

| Usage | Example | Purpose |
| :--- | :--- | :--- |
| **Call base constructor** | `base(name, yearBuilt)` | Initialize base class fields. |
| **Call base method** | `base.DisplayInfo()` | Execute base class logic. |
| **Access base field** | `base.Name` | Access hidden base class member. |

```csharp
public override void DisplayInfo()
{
    // Call base class implementation first
    base.DisplayInfo();
    
    // Add derived class details
    Console.WriteLine($"  Extra info from derived class");
}
```

#### Important Rules of Inheritance

| Rule | Explanation |
| :--- | :--- |
| **Single Inheritance** | C# only supports single inheritance (one base class). |
| **Multiple Inheritance Not Allowed** | Cannot inherit from multiple classes (but interfaces can be implemented). |
| **Constructors Chain** | Base class constructors are called before derived class constructors. |
| **`sealed` Classes** | Cannot be inherited from (`sealed class Building`). |
| **`sealed` Methods** | Cannot be overridden further. |
| **`abstract` Classes** | Cannot be instantiated; must be inherited. |

#### Challenge to Test Your Understanding

> **What will this code output?**

```csharp
public class Vehicle
{
    public string Brand { get; set; }
    public int Year { get; set; }

    public Vehicle(string brand, int year)
    {
        Brand = brand;
        Year = year;
        Console.WriteLine("Vehicle constructor");
    }

    public virtual void Start()
    {
        Console.WriteLine("Vehicle starting...");
    }
}

public class Car : Vehicle
{
    public int NumberOfDoors { get; set; }

    public Car(string brand, int year, int doors) : base(brand, year)
    {
        NumberOfDoors = doors;
        Console.WriteLine("Car constructor");
    }

    public override void Start()
    {
        base.Start();
        Console.WriteLine($"Car {Brand} with {NumberOfDoors} doors starting...");
    }
}

class Program
{
    static void Main()
    {
        Car myCar = new Car("Toyota", 2020, 4);
        Console.WriteLine();
        myCar.Start();
    }
}
```
**Output:**
```
Vehicle constructor
Car constructor

Vehicle starting...
Car Toyota with 4 doors starting...
```

**Explanation:**
1. Constructor chain: `Car` calls `Vehicle` first.
2. `Vehicle` constructor prints "Vehicle constructor".
3. `Car` constructor prints "Car constructor".
4. `myCar.Start()` calls `Car.Start()` (override).
5. `Car.Start()` calls `base.Start()` first (prints "Vehicle starting...").
6. Then prints the car-specific message.


| Rule | Explanation |
| :--- | :--- |
| **Use inheritance for "is-a" relationships** | A `Dog` **is an** `Animal`; a `CommercialBuilding` **is a** `Building`. |
| **Use `protected` for base class members** | Allows derived classes to access while keeping encapsulation. |
| **Use `virtual`/`override` for extensibility** | Enables polymorphic behavior. |
| **Call `base` constructors explicitly** | Ensure base class is properly initialized. |
| **Avoid deep inheritance hierarchies** | Keep inheritance depth manageable (2-3 levels). |
| **Prefer composition over inheritance** | When the relationship is "has-a" rather than "is-a". |
