#### Classes and objects
- In this chapter we cover another fundamental topic, object-oriented programming. We learn how to define classes and instantiate objects from them.
-  We also learn how to define `class fields`, `constructors`, `methods` and `properties`.
-  **Object-oriented programming** is a programming paradigm based on `objects` having both `data` and `methods`.
  - The Classes act as blueprints for objects as in the real world
    > for example, an object instantiated from a building Class has a color, a height and a count of a doors and so on. So far on this course we have had only one class and method, the Main method.
- [ ] A class can be declared by using the class keyword followed by a unique identifier:
```csharp
public class Building
{
    /* fields, properties, methods */
}
```
- [ ] `public` is the **access modifier** in the declaration and means that anyone can create instances of the class.
- [ ] The class naming convention should follow `PascalCase`,
> meaning capitalizing the first letter of each word.
- [ ] As mentioned, objects are entities based on class.
- [ ] Objects are created using the new keyword followed by the class name.
- [ ] A reference to an object is returned.
```csharp
Building object1 = new Building();
```
- A `constructor` is a method which is automatically invoked when an instance of  a class (object) is created.
- The constructor is useful to initialize and set default values for the object fields.
> A class may have several constructors that take different arguments. An example constructor for our Building class could be defined as follows:
```csharp
public Building(string name, int year, int sqm)
{
     this.Name = name;
     this.Year = year;
     this.LeasableArea = sqm;
}
```


#### Core OOP Concepts

| Concept | Definition | Analogy | Example |
| :--- | :--- | :--- | :--- |
| **Class** | A blueprint or template that defines the structure and behavior of objects. | An **architect's blueprint** for a house—it defines what a house *can* have. | `public class Building { }` |
| **Object** | An instance of a class—a concrete entity in memory. | The **actual house** built from the blueprint. | `Building myHouse = new Building();` |
| **Field** | A variable declared inside a class that stores data (state). | The **attributes** of the house (color, height, door count). | `private string color;` |
| **Constructor** | A special method invoked when an object is created; initializes fields. | The **construction crew** building the house according to the blueprint. | `public Building(string name) { Name = name; }` |
| **Method** | A function defined inside a class that performs actions (behavior). | The **actions** a house can perform (open door, turn on lights). | `public void OpenDoor() { }` |
| **Property** | A member that provides a flexible mechanism to read, write, or compute fields. | The **intercom system**—controls access to the inside (encapsulation). | `public string Name { get; set; }` |

#### Class Declaration Syntax Breakdown

| Component | Syntax | Explanation | Example |
| :--- | :--- | :--- | :--- |
| **Access Modifier** | `public`, `private`, `internal`, `protected` | Defines who can access the class. `public` means anyone can use it. | `public class Building` |
| **Class Keyword** | `class` | Indicates that you're defining a class. | `class Building` |
| **Class Name** | `Identifier` | Must follow PascalCase naming convention. | `Building`, `Person`, `Car` |
| **Class Body** | `{ /* members */ }` | Contains fields, properties, methods, and constructors. | `{ public string Name; }` |

#### Object Instantiation (Creating Objects)

| Aspect | Syntax | Explanation | Example |
| :--- | :--- | :--- | :--- |
| **Declaration** | `ClassName variableName;` | Declares a reference variable to hold an object. | `Building myHouse;` |
| **Instantiation** | `new ClassName();` | Allocates memory and creates an instance of the class. | `new Building();` |
| **Combined** | `ClassName variableName = new ClassName();` | Declares and instantiates in one statement. | `Building myHouse = new Building();` |
| **With Arguments** | `new ClassName(arg1, arg2);` | Calls a constructor with parameters. | `new Building("MyHouse", 2020, 150);` |

#### Constructor Details

| Concept | Explanation | Example |
| :--- | :--- | :--- |
| **Purpose** | Initializes object state (fields/properties) when the object is created. | `public Building() { Name = "Unknown"; }` |
| **Default Constructor** | Provided automatically if no constructors are defined. Sets fields to default values. | `Building b = new Building();` |
| **Parameterized Constructor** | Accepts arguments to set custom initial values. | `public Building(string name) { Name = name; }` |
| **Overloaded Constructors** | Multiple constructors with different parameters. | `public Building() { }` <br> `public Building(string name) { }` |
| **`this` Keyword** | Refers to the current instance—used to distinguish between parameters and fields. | `this.Name = name;` |

#### The `new` Keyword – What Happens Behind the Scenes

| Step | Action | Description |
| :--- | :--- | :--- |
| **1** | **Memory Allocation** | Allocates memory on the heap for the new object. |
| **2** | **Initialize Fields** | Sets fields to default values (0 for numbers, null for references, false for bool). |
| **3** | **Constructor Call** | Invokes the constructor to initialize the object with specific values. |
| **4** | **Return Reference** | Returns a reference (memory address) to the new object. |

```csharp
Building myHouse = new Building("Cottage", 1995, 120);
// Step 1: Allocate memory
// Step 2: Fields default: name = null, year = 0, sqm = 0
// Step 3: Constructor sets: name = "Cottage", year = 1995, sqm = 120
// Step 4: myHouse points to the memory location
```

#### Complete `Building` Class Example

```csharp
using System;

public class Building
{
    // Fields
    private string name;
    private int yearBuilt;
    private int leasableArea;
    private bool isOccupied;

    // Properties
    public string Name
    {
        get { return name; }
        set { name = value; }
    }

    public int YearBuilt
    {
        get { return yearBuilt; }
        set { yearBuilt = value; }
    }

    public int LeasableArea
    {
        get { return leasableArea; }
        set { leasableArea = value; }
    }

    public bool IsOccupied
    {
        get { return isOccupied; }
        set { isOccupied = value; }
    }

    // Default Constructor
    public Building()
    {
        name = "Unknown";
        yearBuilt = 2000;
        leasableArea = 0;
        isOccupied = false;
    }

    // Parameterized Constructor
    public Building(string name, int yearBuilt, int leasableArea)
    {
        this.name = name;
        this.yearBuilt = yearBuilt;
        this.leasableArea = leasableArea;
        this.isOccupied = false;
    }

    // Method
    public void DisplayInfo()
    {
        Console.WriteLine($"Building: {name}");
        Console.WriteLine($"  Year Built: {yearBuilt}");
        Console.WriteLine($"  Leasable Area: {leasableArea} sqm");
        Console.WriteLine($"  Occupied: {(isOccupied ? "Yes" : "No")}");
    }

    // Method
    public void ToggleOccupancy()
    {
        isOccupied = !isOccupied;
        Console.WriteLine($"Building '{name}' is now {(isOccupied ? "occupied" : "vacant")}.");
    }
}

class Program
{
    static void Main(string[] args)
    {
        // Create objects
        Building building1 = new Building();
        Building building2 = new Building("Sky Tower", 2010, 5000);

        // Use objects
        building1.DisplayInfo();
        Console.WriteLine();
        building2.DisplayInfo();

        Console.WriteLine();
        building2.ToggleOccupancy();
        building2.DisplayInfo();
    }
}
```

#### Access Modifiers (Common Ones)

| Modifier | Access Level | Description |
| :--- | :--- | :--- |
| **`public`** | Anywhere | Accessible from any other code in the same assembly or another assembly. |
| **`private`** | Same class only | Accessible only within the declaring class. |
| **`protected`** | Same class or derived classes | Accessible within the declaring class and any derived classes. |
| **`internal`** | Same assembly | Accessible only within the same assembly (project). |
| **`protected internal`** | Same assembly or derived classes | Accessible within the same assembly OR in derived classes in other assemblies. |
| **`private protected`** | Same assembly AND derived classes | Accessible only within the same assembly and only in derived classes. |

#### Naming Conventions for Class Members

| Member Type | Naming Convention | Example |
| :--- | :--- | :--- |
| **Class** | PascalCase | `Building`, `Person`, `CustomerManager` |
| **Method** | PascalCase | `DisplayInfo()`, `CalculateArea()` |
| **Property** | PascalCase | `Name`, `YearBuilt`, `IsOccupied` |
| **Public Field** | PascalCase (rare) | `public int MaxCapacity;` |
| **Private Field** | `_camelCase` (preferred) or `camelCase` | `_name`, `_yearBuilt`, `_isOccupied` |
| **Constructor** | PascalCase (matches class name) | `Building()`, `Building(string name)` |
| **Parameter** | camelCase | `name`, `yearBuilt`, `leasableArea` |



#### The Golden Rules

| Rule | Explanation |
| :--- | :--- |
| **Classes are blueprints** | They define the structure and behavior of objects. |
| **Objects are instances** | Created using the `new` keyword. |
| **Constructors initialize** | They set initial values for object fields. |
| **Use `this` for clarity** | Distinguishes fields from parameters with the same name. |
| **Follow naming conventions** | PascalCase for classes, methods, properties; camelCase for parameters; `_camelCase` for private fields. |
| **Encapsulate data** | Use private fields with public properties/methods to control access. |
