#### Methods
- **Methods** are code blocks belonging to a `class`, `struct` or `interface` including a series of statements.
- A `method` is only run if it is called from some other part of code with (optional) method `arguments`. The purpose of a method is to perform actions related to the object. Let us see an example of a method definition.
```csharp
class Building
{
    private int year = 2020;

    public int Built()
    {
         return this.year;
    }
}
```
- [ ] The example class has one private integral field and a value assigned to it.
- [ ] The public method, without access restrictions, simply returns the value of the field.
- [ ] The public keyword in the method declaration makes the method accessible everywhere from the program.
- [ ] The return type of the Built() function is int, which means that it returns an integral value.
> If the method is not returning anything it should be using void keyword. After the return type the method name is defined followed by optional method parameters placed in parenthesis. Now we have a Class and a method, but by themselves, they do nothing. Next, we make use of the class by creating an object and calling the only method. See the next example for a complete program.

#### Methods – Overview

| Aspect | Description |
| :--- | :--- |
| **Definition** | A code block containing a series of statements that perform a specific action. |
| **Purpose** | Encapsulate behavior, promote code reuse, and organize logic. |
| **Invocation** | Only runs when called from another part of the code. |
| **Components** | Access modifier, return type, name, parameters (optional), body. |

#### Method Declaration Breakdown

| Component | Description | Example |
| :--- | :--- | :--- |
| **Access Modifier** | Defines who can call the method. | `public`, `private`, `protected`, `internal` |
| **Return Type** | The type of value the method returns. Use `void` for no return. | `int`, `string`, `void`, `Building` |
| **Method Name** | Follows PascalCase convention. | `Built()`, `CalculateArea()` |
| **Parameters** | Input values passed to the method (optional). | `(int year)`, `(string name, int age)` |
| **Method Body** | The code that executes when the method is called. | `{ return this.year; }` |

#### Complete Program (Based on Your Description)

```csharp
using System;

class Building
{
    // Private field
    private int year = 2020;

    // Public method - returns the year
    public int Built()
    {
        return this.year;
    }

    // Method with no return value (void)
    public void DisplayInfo()
    {
        Console.WriteLine($"Building built in: {this.year}");
    }
}

class Program
{
    static void Main()
    {
        // Create an object
        Building myBuilding = new Building();

        // Call the method
        int buildYear = myBuilding.Built();
        Console.WriteLine($"Building year: {buildYear}"); // Output: Building year: 2020

        // Call void method
        myBuilding.DisplayInfo(); // Output: Building built in: 2020
    }
}
```

#### Method Return Types

| Return Type | Description | Example Method |
| :--- | :--- | :--- |
| **`void`** | Returns nothing (no value). | `public void DisplayInfo() { Console.WriteLine("Hello"); }` |
| **`int`** | Returns an integer value. | `public int GetAge() { return 25; }` |
| **`string`** | Returns a string value. | `public string GetName() { return "Alice"; }` |
| **`bool`** | Returns a Boolean value. | `public bool IsValid() { return true; }` |
| **`Building`** | Returns an object of type `Building`. | `public Building GetBuilding() { return new Building(); }` |
| **`int[]`** | Returns an array of integers. | `public int[] GetNumbers() { return new int[] { 1, 2, 3 }; }` |

#### Method Access Modifiers

| Modifier | Access Level | When to Use |
| :--- | :--- | :--- |
| **`public`** | Accessible from anywhere. | Methods that provide functionality to external code. |
| **`private`** | Accessible only within the same class. | Helper methods used internally. |
| **`protected`** | Accessible in the class and derived classes. | Methods for inheritance scenarios. |
| **`internal`** | Accessible only within the same assembly (project). | Methods used only within the same project. |
| **`private protected`** | Accessible in the same assembly AND derived classes. | Limited access for inheritance within the same project. |

#### Method Overloading

Methods can have the **same name** but different parameters:

```csharp
using System;

class Building
{
    private string name;
    private int year;

    // Default constructor
    public Building()
    {
        name = "Unknown";
        year = 2000;
    }

    // Parameterized constructor
    public Building(string name, int year)
    {
        this.name = name;
        this.year = year;
    }

    // Method overload 1 - no parameters
    public void DisplayInfo()
    {
        Console.WriteLine($"Building: {name}, Year: {year}");
    }

    // Method overload 2 - one parameter (string)
    public void DisplayInfo(string prefix)
    {
        Console.WriteLine($"{prefix} Building: {name}, Year: {year}");
    }

    // Method overload 3 - two parameters (string, int)
    public void DisplayInfo(string prefix, int minYear)
    {
        if (year >= minYear)
        {
            Console.WriteLine($"{prefix} Building: {name}, Year: {year}");
        }
        else
        {
            Console.WriteLine($"{prefix} Building '{name}' was built before {minYear}");
        }
    }
}

class Program
{
    static void Main()
    {
        Building b = new Building("Sky Tower", 2020);

        b.DisplayInfo();                       // Calls overload 1
        b.DisplayInfo("INFO:");                // Calls overload 2
        b.DisplayInfo("STATUS:", 2010);        // Calls overload 3
    }
}
```

**Output:**
```
Building: Sky Tower, Year: 2020
INFO: Building: Sky Tower, Year: 2020
STATUS: Building: Sky Tower, Year: 2020
```

#### Method Parameters – Pass by Value vs Reference

| Parameter Type | Syntax | Description | Example |
| :--- | :--- | :--- | :--- |
| **Value (default)** | `int value` | Passes a copy of the value. | `void Add(int x) { x++; }` |
| **Reference (`ref`)** | `ref int value` | Passes a reference; changes affect the original. | `void Add(ref int x) { x++; }` |
| **Output (`out`)** | `out int value` | Passes a reference; must be assigned in the method. | `void Parse(string s, out int result)` |
| **`in` (read-only)** | `in int value` | Passes a reference but cannot modify it. | `void Print(in int value) { Console.WriteLine(value); }` |
| **Params** | `params int[] numbers` | Accepts a variable number of arguments. | `void Sum(params int[] numbers)` |

#### Method Examples: All Parameter Types

```csharp
using System;

class Calculator
{
    // 1. Pass by Value (default) - Creates a copy
    public void AddValue(int x)
    {
        x++;
        Console.WriteLine($"Inside method: {x}");
    }

    // 2. Pass by Reference (ref) - Modifies original
    public void AddRef(ref int x)
    {
        x++;
        Console.WriteLine($"Inside method: {x}");
    }

    // 3. Output Parameter (out) - Must assign a value
    public void Divide(int a, int b, out int quotient, out int remainder)
    {
        quotient = a / b;
        remainder = a % b;
    }

    // 4. Params - Variable number of arguments
    public int Sum(params int[] numbers)
    {
        int total = 0;
        foreach (int num in numbers)
        {
            total += num;
        }
        return total;
    }
}

class Program
{
    static void Main()
    {
        Calculator calc = new Calculator();

        // Value parameter
        int value = 5;
        calc.AddValue(value);
        Console.WriteLine($"After method: {value}"); // Still 5

        // Reference parameter (ref)
        int refValue = 5;
        calc.AddRef(ref refValue);
        Console.WriteLine($"After method: {refValue}"); // Now 6

        // Output parameter (out)
        int quotient, remainder;
        calc.Divide(10, 3, out quotient, out remainder);
        Console.WriteLine($"Quotient: {quotient}, Remainder: {remainder}");

        // Params
        int sum1 = calc.Sum(1, 2, 3);
        int sum2 = calc.Sum(10, 20, 30, 40, 50);
        int sum3 = calc.Sum(5, 10);
        Console.WriteLine($"Sums: {sum1}, {sum2}, {sum3}");
    }
}
```

**Output:**
```
Inside method: 6
After method: 5
Inside method: 6
After method: 6
Quotient: 3, Remainder: 1
Sums: 6, 150, 15
```

#### Complete Building Class with Multiple Methods

```csharp
using System;

public class Building
{
    // Fields
    private string _name;
    private int _yearBuilt;
    private int _doorCount;
    private double _leasableArea;
    private bool _isOccupied;

    // Constructor
    public Building(string name, int yearBuilt, int doorCount, double leasableArea)
    {
        _name = name;
        _yearBuilt = yearBuilt;
        _doorCount = doorCount;
        _leasableArea = leasableArea;
        _isOccupied = false;
    }

    // ============ GETTER METHODS (Read Data) ============

    public string GetName() => _name;

    public int GetYearBuilt() => _yearBuilt;

    public int GetDoorCount() => _doorCount;

    public double GetLeasableArea() => _leasableArea;

    public bool IsOccupied() => _isOccupied;

    // ============ SETTER METHODS (Modify Data) ============

    public void SetDoorCount(int count)
    {
        if (count < 0)
        {
            Console.WriteLine("Error: Door count cannot be negative!");
            return;
        }
        _doorCount = count;
    }

    public void SetLeasableArea(double area)
    {
        if (area < 0)
        {
            Console.WriteLine("Error: Area cannot be negative!");
            return;
        }
        _leasableArea = area;
    }

    // ============ ACTION METHODS ============

    public void ToggleOccupancy()
    {
        _isOccupied = !_isOccupied;
        Console.WriteLine($"Building '{_name}' is now {(_isOccupied ? "occupied" : "vacant")}.");
    }

    public void Rename(string newName)
    {
        if (string.IsNullOrEmpty(newName))
        {
            Console.WriteLine("Error: Name cannot be empty!");
            return;
        }
        _name = newName;
        Console.WriteLine($"Building renamed to '{_name}'.");
    }

    // ============ CALCULATION METHODS ============

    public int GetAge()
    {
        return DateTime.Now.Year - _yearBuilt;
    }

    public double GetLeasableAreaPerDoor()
    {
        if (_doorCount == 0)
        {
            Console.WriteLine("Warning: No doors! Cannot calculate area per door.");
            return 0;
        }
        return _leasableArea / _doorCount;
    }

    // ============ DISPLAY METHODS ============

    public void DisplayInfo()
    {
        Console.WriteLine("═══════════════════════════════");
        Console.WriteLine($"Building Information:");
        Console.WriteLine($"  Name:                {_name}");
        Console.WriteLine($"  Year Built:          {_yearBuilt}");
        Console.WriteLine($"  Age:                 {GetAge()} years");
        Console.WriteLine($"  Door Count:          {_doorCount}");
        Console.WriteLine($"  Leasable Area:       {_leasableArea:F2} sqm");
        Console.WriteLine($"  Area per Door:       {GetLeasableAreaPerDoor():F2} sqm/door");
        Console.WriteLine($"  Occupied:            {(_isOccupied ? "Yes" : "No")}");
        Console.WriteLine("═══════════════════════════════");
    }
}

class Program
{
    static void Main()
    {
        Console.WriteLine("=== Building Management System ===\n");

        // Create a building
        Building office = new Building("Tech Tower", 2018, 12, 2400.5);

        // Display initial info
        office.DisplayInfo();

        Console.WriteLine("\n--- Making Changes ---\n");

        // Use methods
        office.Rename("Innovation Tower");
        office.SetDoorCount(15);
        office.ToggleOccupancy();
        office.SetLeasableArea(2800.75);

        Console.WriteLine();

        // Display updated info
        office.DisplayInfo();

        Console.WriteLine("\n--- Calculations ---\n");
        Console.WriteLine($"Age of building: {office.GetAge()} years");
        Console.WriteLine($"Area per door: {office.GetLeasableAreaPerDoor():F2} sqm");
        Console.WriteLine($"Is occupied? {office.IsOccupied()}");
    }
}
```

#### Method Naming Conventions

| Method Type | Naming Convention | Example |
| :--- | :--- | :--- |
| **Getter** | `Get` + PropertyName | `GetName()`, `GetAge()` |
| **Setter** | `Set` + PropertyName | `SetName()`, `SetDoorCount()` |
| **Boolean** | `Is` + Condition | `IsOccupied()`, `IsValid()` |
| **Action** | Verb + Object | `ToggleOccupancy()`, `CalculateArea()` |
| **Event Handler** | `On` + EventName | `OnClick()`, `OnLoad()` |

#### Common Mistakes and Best Practices

| ❌ Bad Practice | ✅ Good Practice | Why |
| :--- | :--- | :--- |
| `public void DisplayInfo() { // 100 lines of code }` | Break into smaller methods | Single Responsibility Principle - one method does one thing. |
| `public void DoEverything(string input) { ... }` | Use specific method names | Clear, descriptive names make code self-documenting. |
| `int result = obj.Compute(); // Does nothing...` | Ensure methods do what they say | Methods should match their name and documentation. |
| `public int GetValue() { /* modifies state */ }` | Getter should not modify state | Getters should be side-effect free. |
| `public void Validate(string input) { if (!valid) return; }` | Return `bool` or throw exception | Indicate success/failure clearly. |

#### Challenge to Test Your Understanding

> **What will this code output?**

```csharp
public class Counter
{
    private int _count = 0;

    public void Increment()
    {
        _count++;
        Console.WriteLine($"Count: {_count}");
    }

    public void Decrement()
    {
        if (_count > 0)
        {
            _count--;
            Console.WriteLine($"Count: {_count}");
        }
        else
        {
            Console.WriteLine("Cannot decrement below zero!");
        }
    }

    public int GetCount()
    {
        return _count;
    }

    public void Reset()
    {
        _count = 0;
        Console.WriteLine("Counter reset to 0.");
    }
}

class Program
{
    static void Main()
    {
        Counter c = new Counter();
        c.Increment();
        c.Increment();
        c.Decrement();
        c.Decrement();
        c.Decrement();
        c.Reset();
        c.Increment();
        Console.WriteLine($"Final count: {c.GetCount()}");
    }
}
```

**Output:**
```
Count: 1
Count: 2
Count: 1
Count: 0
Cannot decrement below zero!
Counter reset to 0.
Count: 1
Final count: 1
```

**Explanation:**
1. Increment twice → count = 2
2. Decrement once → count = 1
3. Decrement again → count = 0
4. Decrement again → error (cannot go below zero)
5. Reset → count = 0
6. Increment → count = 1
7. Final count = 1

#### Summary: The Golden Rules

| Rule | Explanation |
| :--- | :--- |
| **Methods should do one thing** | Follow Single Responsibility Principle. |
| **Use meaningful names** | Method names should clearly describe what they do. |
| **Choose the right return type** | Use `void` for no return; use appropriate types otherwise. |
| **Use `ref` and `out` sparingly** | Prefer returning values or using classes for complex data. |
| **Keep methods focused** | A method should be small and focused on a single task. |
| **Encapsulate behavior** | Methods should operate on the object's state. |
