#### Exception handling
- Sometimes operations in a program may come up with an unexpected problem, called an exception. In C# the exceptions are handled with try-catch, try-finally and try-catch-finally statements. The syntax of is the following:
```csharp
try {   
    /* statements possibly causing exception */
} catch( ExceptionName e ) {   
    /* error handling code */
} finally {   
    /* statements to be executed */
}
```
- The statements in the Try block are executed until an exception is thrown or all statements are executed successfully.
- Should a specified exception occur the statements in that catch block will be executed.
- It is possible to introduce several catch blocks in the same try-catch statement.
- In the following example, the `try-catch` statement is used to recover from a scenario where file deletion is not successful for example because of insufficient access level.


#### Exception Handling – Overview

| Term | Definition |
| :--- | :--- |
| **Exception** | An unexpected problem that occurs during program execution (e.g., file not found, division by zero). |
| **Try Block** | Contains code that might throw an exception. |
| **Catch Block** | Handles specific exceptions when they occur. |
| **Finally Block** | Always executes, regardless of whether an exception occurred (for cleanup). |

#### Complete Example (Based on Your Description)

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string fileName = "important.txt";

        try
        {
            Console.WriteLine($"Attempting to delete file: {fileName}");

            // Check if the file exists
            if (File.Exists(fileName))
            {
                File.Delete(fileName);
                Console.WriteLine($"File '{fileName}' deleted successfully.");
            }
            else
            {
                Console.WriteLine($"File '{fileName}' does not exist.");
            }
        }
        catch (UnauthorizedAccessException ex)
        {
            Console.WriteLine($"Error: Insufficient permissions to delete the file.");
            Console.WriteLine($"Details: {ex.Message}");
        }
        catch (IOException ex)
        {
            Console.WriteLine($"Error: I/O error occurred while deleting the file.");
            Console.WriteLine($"Details: {ex.Message}");
        }
        catch (Exception ex)
        {
            Console.WriteLine($"Error: An unexpected error occurred.");
            Console.WriteLine($"Details: {ex.Message}");
        }
        finally
        {
            Console.WriteLine("File deletion attempt completed.");
        }
    }
}
```

#### Try-Catch-Finally Structure

| Block | Purpose | Always Executes? |
| :--- | :--- | :--- |
| **`try`** | Contains code that might throw an exception. | ✅ Always (until exception or completion) |
| **`catch`** | Handles specific exceptions. | ❌ Only if matching exception occurs |
| **`finally`** | Cleanup code (close files, release resources). | ✅ Always (after try or catch) |

#### Common Exception Types

| Exception Type | Description | When It Occurs |
| :--- | :--- | :--- |
| **`Exception`** | Base class for all exceptions. | Catch-all (use last). |
| **`SystemException`** | Base for system exceptions. | Framework exceptions. |
| **`ArgumentException`** | Invalid argument. | Passing invalid parameters. |
| **`ArgumentNullException`** | Argument is `null`. | `null` when not allowed. |
| **`ArgumentOutOfRangeException`** | Argument out of range. | Index or value out of valid range. |
| **`FileNotFoundException`** | File not found. | Missing file. |
| **`DirectoryNotFoundException`** | Directory not found. | Missing directory. |
| **`IOException`** | I/O error. | Disk full, network error, etc. |
| **`UnauthorizedAccessException`** | Access denied. | Insufficient permissions. |
| **`DivideByZeroException`** | Division by zero. | Integer division by zero. |
| **`NullReferenceException`** | Null reference. | Accessing a null object. |
| **`IndexOutOfRangeException`** | Index out of bounds. | Array index out of range. |
| **`FormatException`** | Invalid format. | Invalid input format. |
| **`OverflowException`** | Overflow. | Value too large for type. |

#### Multiple Catch Blocks

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string filePath = @"C:\MyApp\Data\config.txt";

        try
        {
            // Multiple operations that might cause different exceptions
            string content = File.ReadAllText(filePath);
            int number = int.Parse(content);
            Console.WriteLine($"Read number: {number}");
        }
        catch (ArgumentNullException ex)
        {
            Console.WriteLine($"Error: File path is null. {ex.Message}");
        }
        catch (ArgumentException ex)
        {
            Console.WriteLine($"Error: Invalid file path. {ex.Message}");
        }
        catch (FileNotFoundException ex)
        {
            Console.WriteLine($"Error: File not found. {ex.Message}");
        }
        catch (DirectoryNotFoundException ex)
        {
            Console.WriteLine($"Error: Directory not found. {ex.Message}");
        }
        catch (UnauthorizedAccessException ex)
        {
            Console.WriteLine($"Error: Access denied. {ex.Message}");
        }
        catch (FormatException ex)
        {
            Console.WriteLine($"Error: Invalid number format. {ex.Message}");
        }
        catch (OverflowException ex)
        {
            Console.WriteLine($"Error: Number is too large or too small. {ex.Message}");
        }
        catch (IOException ex)
        {
            Console.WriteLine($"Error: I/O error. {ex.Message}");
        }
        catch (Exception ex)
        {
            // Catch-all for unexpected exceptions
            Console.WriteLine($"Error: Unexpected error. {ex.Message}");
        }
        finally
        {
            Console.WriteLine("Operation completed.");
        }
    }
}
```

#### Try-Finally (No Catch)

Sometimes you only need to ensure cleanup happens, even if you don't handle the exception:

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        StreamWriter writer = null;

        try
        {
            writer = new StreamWriter("data.txt");
            writer.WriteLine("Hello, World!");
            // If an exception occurs here, the file is still closed.
        }
        finally
        {
            // Always executed - even if an exception occurred
            if (writer != null)
            {
                writer.Close();
                writer.Dispose();
                Console.WriteLine("File closed and resources released.");
            }
        }

        // This is equivalent to using the 'using' statement:
        // using (StreamWriter writer = new StreamWriter("data.txt"))
        // {
        //     writer.WriteLine("Hello, World!");
        // }
    }
}
```

#### Throwing Exceptions

You can also **throw** your own exceptions to signal errors:

```csharp
using System;

class Program
{
    static void Main()
    {
        try
        {
            int age = GetAgeFromUser("Enter your age: ");
            Console.WriteLine($"Your age is: {age}");
        }
        catch (ArgumentOutOfRangeException ex)
        {
            Console.WriteLine($"Age error: {ex.Message}");
        }
        catch (FormatException ex)
        {
            Console.WriteLine($"Format error: {ex.Message}");
        }
        catch (Exception ex)
        {
            Console.WriteLine($"Error: {ex.Message}");
        }
    }

    static int GetAgeFromUser(string prompt)
    {
        Console.Write(prompt);
        string input = Console.ReadLine();

        // Check for null or empty input
        if (string.IsNullOrEmpty(input))
        {
            throw new ArgumentException("Input cannot be null or empty.");
        }

        // Try to parse the input
        if (!int.TryParse(input, out int age))
        {
            throw new FormatException("Please enter a valid number.");
        }

        // Validate the age range
        if (age < 0 || age > 120)
        {
            throw new ArgumentOutOfRangeException(
                nameof(age),
                "Age must be between 0 and 120."
            );
        }

        return age;
    }
}
```

#### Best Practices for Exception Handling

| Practice | Explanation | Example |
| :--- | :--- | :--- |
| **Catch specific exceptions first** | Order from most specific to most general. | `catch (FileNotFoundException)` before `catch (Exception)` |
| **Use `finally` for cleanup** | Close files, release resources. | `finally { stream.Close(); }` |
| **Don't catch exceptions you can't handle** | Let them propagate to higher levels. | Only catch what you can meaningfully handle. |
| **Use `using` for disposable objects** | Automatically handles cleanup. | `using (StreamReader reader = new StreamReader(file))` |
| **Provide meaningful error messages** | Help the user understand the problem. | `"File 'data.txt' not found. Please check the path."` |
| **Log exceptions** | For debugging and auditing. | `Logger.LogError(ex);` |
| **Don't use exception handling for flow control** | Exceptions are for exceptional conditions. | Don't use `try-catch` to check if a file exists—use `File.Exists()`. |

#### The `using` Statement (Cleaner Resource Management)

```csharp
// Without 'using' (manual cleanup)
StreamReader reader = null;
try
{
    reader = new StreamReader("data.txt");
    string content = reader.ReadToEnd();
    Console.WriteLine(content);
}
finally
{
    if (reader != null)
    {
        reader.Dispose();
    }
}

// With 'using' (automatic cleanup)
using (StreamReader reader = new StreamReader("data.txt"))
{
    string content = reader.ReadToEnd();
    Console.WriteLine(content);
}
```

#### Practical Example: Complete Exception Handling

```csharp
using System;
using System.IO;

class FileManager
{
    private string _filePath;

    public FileManager(string filePath)
    {
        _filePath = filePath;
    }

    public string ReadFileSafely()
    {
        try
        {
            // Check if file exists
            if (!File.Exists(_filePath))
            {
                throw new FileNotFoundException($"File '{_filePath}' not found.");
            }

            // Read the file
            using (StreamReader reader = new StreamReader(_filePath))
            {
                return reader.ReadToEnd();
            }
        }
        catch (FileNotFoundException ex)
        {
            Console.WriteLine($"[ERROR] File not found: {ex.Message}");
            return null;
        }
        catch (DirectoryNotFoundException ex)
        {
            Console.WriteLine($"[ERROR] Directory not found: {ex.Message}");
            return null;
        }
        catch (UnauthorizedAccessException ex)
        {
            Console.WriteLine($"[ERROR] Access denied: {ex.Message}");
            return null;
        }
        catch (IOException ex)
        {
            Console.WriteLine($"[ERROR] I/O error: {ex.Message}");
            return null;
        }
        catch (Exception ex)
        {
            Console.WriteLine($"[ERROR] Unexpected error: {ex.Message}");
            Console.WriteLine($"  Stack trace: {ex.StackTrace}");
            return null;
        }
    }

    public bool WriteFileSafely(string content)
    {
        try
        {
            using (StreamWriter writer = new StreamWriter(_filePath))
            {
                writer.Write(content);
            }
            Console.WriteLine($"Successfully wrote to '{_filePath}'.");
            return true;
        }
        catch (DirectoryNotFoundException ex)
        {
            Console.WriteLine($"[ERROR] Directory not found: {ex.Message}");
            return false;
        }
        catch (UnauthorizedAccessException ex)
        {
            Console.WriteLine($"[ERROR] Access denied: {ex.Message}");
            return false;
        }
        catch (IOException ex)
        {
            Console.WriteLine($"[ERROR] I/O error: {ex.Message}");
            return false;
        }
        catch (Exception ex)
        {
            Console.WriteLine($"[ERROR] Unexpected error: {ex.Message}");
            return false;
        }
    }
}

class Program
{
    static void Main()
    {
        Console.WriteLine("=== File Manager with Exception Handling ===\n");

        FileManager manager = new FileManager("test.txt");

        // Write to file
        Console.WriteLine("--- Writing to file ---");
        manager.WriteFileSafely("Hello, World!\nThis is a test file.");

        // Read from file
        Console.WriteLine("\n--- Reading from file ---");
        string content = manager.ReadFileSafely();
        if (content != null)
        {
            Console.WriteLine($"Content:\n{content}");
        }

        // Try to read a non-existent file
        Console.WriteLine("\n--- Reading non-existent file ---");
        FileManager badManager = new FileManager("nonexistent.txt");
        string result = badManager.ReadFileSafely();
        Console.WriteLine($"Result: {(result == null ? "null" : result)}");

        Console.WriteLine("\n=== Program ended ===");
    }
}
```


| Rule | Explanation |
| :--- | :--- |
| **Catch specific exceptions first** | Order catch blocks from most specific to most general. |
| **Use `finally` for cleanup** | Always execute cleanup code. |
| **Use `using` for resources** | Simpler than manual `try-finally`. |
| **Don't catch what you can't handle** | Let exceptions propagate to higher levels. |
| **Provide meaningful messages** | Help users and developers understand the error. |
| **Log exceptions** | For debugging and auditing. |
| **Don't use exceptions for flow control** | Use `if` statements for expected conditions. |
