## C-Advanced-Programming

| Area | Topics | What it's about |
|---|---|---|
| **Generics** | Constraints, covariance/contravariance, generic methods | Reusable, type-safe code |
| **Delegates & events** | `Action`, `Func`, `Predicate`, multicast delegates, event patterns | Callbacks and the observer pattern |
| **Lambda & LINQ** | Query/method syntax, deferred execution, expression trees, `IQueryable` | Querying and transforming data |
| **Async programming** | `async`/`await`, `Task`, `ValueTask`, cancellation tokens, `IAsyncEnumerable` | Non-blocking, scalable code |
| **Multithreading** | `Thread`, `ThreadPool`, `Parallel`, locks, `Interlocked`, `SemaphoreSlim`, concurrent collections | Parallel work and thread safety |
| **Reflection & attributes** | `Type`, `Assembly`, custom attributes, dynamic invocation | Inspecting and using types at runtime |
| **Memory management** | Garbage collector, `IDisposable`, `using`, finalizers, `Span<T>`, `Memory<T>`, `ref struct` | Performance and resource handling |
| **Modern C# features** | Records, pattern matching, nullable reference types, `init`, switch expressions, primary constructors | Concise, safer code |
| **OOP & design** | SOLID, design patterns, dependency injection, interfaces vs abstract classes | Architecture and maintainability |
| **Extension & dynamic features** | Extension methods, `dynamic`, `ExpandoObject`, operator overloading, indexers | Extending types and flexible typing |
| **Exception handling** | Custom exceptions, filters (`when`), `finally`, best practices | Robust error handling |
| **Unsafe/interop** | `unsafe` code, pointers, P/Invoke, marshalling | Working with native code |
| **File & I/O** | Streams, serialization (`System.Text.Json`), file handling | Data persistence |
| **Data access** | Entity Framework Core, ADO.NET, Dapper | Working with databases |
